# 坦克大战 Tank Battle

一个用原生 HTML5 Canvas 编写的经典坦克大战（Battle City）网页小游戏，零依赖、单文件即可运行。

## 快速开始

直接用浏览器打开 `index.html` 即可游玩，无需安装任何东西。

也可以在本地起一个静态服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `方向键` / `WASD` | 移动坦克 |
| `空格` / `J` | 射击 |
| `Enter` | 开始 / 重新开始 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |

## 游戏玩法

- **目标**：消灭所有敌方坦克，同时保护己方基地（老鹰）。
- **生命**：初始 3 条命，被击中或基地被毁则游戏结束。
- **关卡**：共 3 关，敌人数量、种类与难度逐关提升。
- **地形**：
  - 🧱 砖墙 —— 可被子弹摧毁
  - 🛡️ 钢墙 —— 不可摧毁（火力满级后可击穿）
  - 💧 河流 —— 坦克无法通行，子弹可飞越
  - 🌲 树林 —— 遮挡坦克
- **道具**（击毁敌人时概率掉落）：
  - ⭐ 星 —— 火力升级（最多 3 级，满级可击穿钢墙）
  - ❤️ 命 —— 增加 1 条生命
  - 🛡️ 盾 —— 短时间无敌护盾
  - 💣 雷 —— 消灭场上所有敌人
  - ❄️ 冻 —— 冻结敌人

## 技术实现

- 纯原生 JavaScript + Canvas 2D，无第三方依赖
- 基于像素网格（13×13）的碰撞检测
- `requestAnimationFrame` 游戏循环，`deltaTime` 控制帧率无关的运动
- Web Audio API 生成音效（无外部音频文件）
